# 01-Bosqich: Dasturchi Yozgan Fayl va Kod Strukturasini Tahlil Qilish

## Maqsad
Kutubxonalar va tashqi modullarni chetga surgan holda, dasturchi tomonidan yaratilgan papkalar iyerarxiyasi, kodlar modulizatsiyasi va fayllar tuzilishini tahlil qilish rejasi.

## Tekshiruv Mezonlari (Checklist)

### 1. Fayllarni Tashkillashtirish Uslubi
- [ ] Dasturchi kodlarni papkalarga ajratishda qaysi tamoyildan foydalangan (Feature-based, Layer-based, Modular)?
- [ ] Fayllarga nom berish standartlari (`naming conventions`) izchilligi (kebab-case, camelCase, PascalCase).

### 2. Modullik va Qayta Ishlatiluvchanlik
- [ ] Yozilgan kodlarda modullik va xususiy funksiyalarning qayta ishlatilishi (Helper utility'lar, custom decorator'lar, custom hook'lar).
- [ ] Kodlarning tarqoqligi yoki bir joyga jamlanganligi (Monolithic file vs Micro-modules).

### 3. Loyihalar Vaqt Oralig'ida Solishtirish
- [ ] Birinchi kommit sanasidan so'nggi kommit sanasigacha fayllarni tashkillash strukturasi qanchalik tartibli bo'lib borganligi.
